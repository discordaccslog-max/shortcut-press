An interactive browser guide to automating Microsoft Excel with macros and VBA: recording macros, the VBA editor, ranges and worksheets in code, variables, loops and decisions, message boxes and buttons, and your own worksheet functions and event macros, with a practice workbook and a finished code module to compare.

What the guide covers

  1. 01

    Record your first macro

    Turn on the Developer tab, record a macro, run it again, and save the workbook so the macro is kept.

  2. 02

    The VBA editor

    Find your recorded code, read a Sub from top to bottom, run and step through it, and use the Immediate window.

  3. 03

    Ranges, sheets and properties

    Refer to cells, ranges and worksheets directly in code, change their properties without selecting them, and group changes with With.

  4. 04

    Variables, loops and decisions

    Store values in variables, find the last row of data, loop through every row, and act only on rows that meet a condition.

  5. 05

    Messages, input and buttons

    Show results with MsgBox, ask for a value with InputBox, handle mistakes gracefully, and run macros from a button on the sheet.

  6. 06

    Your own functions and automatic macros

    Write a function you can use in cells, run code automatically when a sheet changes, and keep everyday macros in the Personal Macro Workbook.

Software required

This guide is written for Microsoft Excel for Windows (Microsoft 365, Excel 2021 or Excel 2024). VBA also works in Excel for Mac, but the editor looks different and some steps change. Macros don't run in Excel for the web. Excel is not included with the guide; you need your own copy or subscription, obtained separately from Microsoft.

About software updates. Software makers update their programs, so menus and button locations can change between versions. This guide is revised when an update changes the steps, and the revised version appears the next time you open it.

What you need

  • A modern web browser (such as Chrome, Edge, Firefox or Safari) on a computer, tablet or phone.
  • Microsoft Excel for Windows (Microsoft 365 or Excel 2021 and later), obtained separately, to follow the steps.
  • An internet connection the first time you open the guide on a device; after that it also works offline.

How the guide works

This is a self-study guide. You read each step, carry it out in your own copy of the software, check your understanding with the quiz, then try the exercise and compare your work with the worked solution. There are no video lessons, no live instruction, no tutoring, and no feedback on your work.

Is this guide a good fit?

Who it's for

  • You repeat the same formatting or tidying steps in Excel every week.
  • You're comfortable with formulas and want to start reading and writing simple code.
  • You've recorded a macro before but couldn't change what it does.

Who it isn't for

  • You want Office Scripts, Python in Excel or Power Automate. The guide covers VBA only.
  • You're new to Excel. Start with Spreadsheet Formulas & Functions.
  • You want video lessons, live help, or someone to review your work.
