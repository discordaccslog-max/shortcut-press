What the guide covers

  1. Preparing data

    What a well-structured table looks like, removing duplicates and blank rows, fixing inconsistent text and dates, and splitting values that were entered into a single column.

  2. Building pivot tables

    Choosing rows, columns and values, switching between sum, count and average, and grouping dates and numbers into useful ranges.

  3. Summarizing and filtering

    Filtering and sorting a pivot table, showing values as a share of a total, and adding calculated fields.

  4. Choosing a chart

    Matching the chart type to the question: comparing categories, showing change over time, showing parts of a whole, and showing how two values relate.

  5. Formatting charts

    Titles, axis labels, colors, gridlines and data labels, and removing clutter so a chart can be read at a glance.

  6. Keeping it current

    Refreshing a pivot table when the source data changes and keeping charts connected to the data they show.
