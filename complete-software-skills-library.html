What the library includes

The library contains all seven guides. Each one is the same complete guide sold on its own page; follow the links for each guide's full contents, level and preview pages.

  1. Spreadsheet Formulas & Functions

    Cell references, lookups, logical, text and date functions, and error handling, for Excel and Google Sheets. Beginner to intermediate level. Uses Microsoft Excel or Google Sheets.

  2. Data Analysis with Pivot Tables & Charts

    Cleaning data, building pivot tables, summarizing and filtering, and choosing and formatting charts. Intermediate level. Uses Microsoft Excel or Google Sheets.

  3. Professional Document Formatting

    Styles, headings, automatic tables of contents, page layout, and reusable templates in Word and Google Docs. Beginner level. Uses Microsoft Word or Google Docs.

  4. 3D Modeling Fundamentals in Blender

    Navigating the interface, modeling with basic shapes, modifiers, materials, lighting, and rendering a scene. Beginner level. Uses Blender.

  5. Video Editing in DaVinci Resolve

    Organizing footage, cutting on the timeline, transitions, titles, color correction, audio cleanup, and exporting. Beginner to intermediate level. Uses DaVinci Resolve.

  6. Interface Design in Figma

    Frames, auto layout, components, styles, and prototyping a simple app screen flow. Beginner to intermediate level. Uses Figma.

  7. Vector Illustration in Inkscape

    Shapes, paths, the pen tool, text, and exporting for print and web. Beginner level. Uses Inkscape.

How the guide works

This is a self-study guide. You read each step, carry it out in your own copy of the software, then do the exercises and compare your work with the worked solutions. There is no video, no live instruction, no tutoring, and no feedback on your work. Everything you get is in the .zip.

What's in the .zip

  • One folder per guide

    Seven folders, one for each guide, so each program's material stays together.

  • Seven PDF guides

    Each skill explained step by step with annotated illustrations, followed by practice exercises with worked solutions.

  • All practice files

    The practice spreadsheets, datasets, documents, project files, footage and illustration files for every guide's exercises.

No software is included. See Software required below.

Is the library a good fit?

  • You work with several of these programs, or plan to.
