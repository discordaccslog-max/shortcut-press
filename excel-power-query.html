An interactive browser guide to cleaning and reshaping data with Power Query in Microsoft Excel: importing files, fixing text and data types, unpivoting wide tables, appending monthly exports, merging lookup tables, and grouping into a report that refreshes with one click, with messy practice files to clean.

What the guide covers

  1. 01

    Get data and the Power Query Editor

    Import a CSV file, find your way around the Power Query Editor, and see how every change is recorded as an applied step.

  2. 02

    Clean text, rows and types

    Trim stray spaces, fix capitals, split a combined column, remove blank and duplicate rows, and set data types.

  3. 03

    Reshape: unpivot and headers

    Turn a wide table with one column per month into a long table that pivot tables and charts can use.

  4. 04

    Append months of data

    Stack monthly exports into one table with Append, or point Power Query at a folder and combine every file in it.

  5. 05

    Merge: look up values from another table

    Join two queries on a shared column to bring in matching values, and choose the right kind of join.

  6. 06

    Group, summarize and refresh

    Group rows into totals, load summaries where you need them, and set queries to refresh so the report updates itself.

Software required

This guide is written for Microsoft Excel for Windows (Microsoft 365, Excel 2021 or Excel 2024), where Power Query is built in under the Data tab. Excel for Mac (Microsoft 365) includes the Power Query editor too, but some options, such as combining files from a folder, may be missing or in different places. Excel is not included with the guide; you need your own copy or subscription, obtained separately from Microsoft.

About software updates. Software makers update their programs, so menus and button locations can change between versions. This guide is revised when an update changes the steps, and the revised version appears the next time you open it.

What you need

  • A modern web browser (such as Chrome, Edge, Firefox or Safari) on a computer, tablet or phone.
  • Microsoft Excel (Microsoft 365 or Excel 2021 and later, for Windows), obtained separately, to follow the steps.
  • An internet connection the first time you open the guide on a device; after that it also works offline.

How the guide works

This is a self-study guide. You read each step, carry it out in your own copy of the software, check your understanding with the quiz, then try the exercise and compare your work with the worked solution. There are no video lessons, no live instruction, no tutoring, and no feedback on your work.

Is this guide a good fit?

Who it's for

  • You clean the same exported data by hand every week or month.
  • You're comfortable with Excel tables and basic formulas and want to stop copying and pasting.
  • You combine data from several files or look values up from another table.

Who it isn't for

  • You're new to Excel. Start with Spreadsheet Formulas & Functions.
  • You want to write advanced M code or connect to company databases. The guide uses the editor's buttons, with a little M where it helps.
  • You want video lessons, live help, or someone to review your work.
